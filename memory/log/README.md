# memory/log/ — 按日记录

一次会话一个文件，命名 `YYYY-MM-DD.md`。同一天有多次会话就追加，不要新建第二个文件。

## 记什么

只记**事件**，不记结论：

- 一次返工：原方案 / 改成了 / 真正的原因
- 一次例外：哪个原则被破了，为什么这次可以破
- 一次澄清：本人主动说出来的偏好（原话尽量保留）

结论不写这里。结论沉淀到 `memory/MEMORY.md`，重复出现三次才升级成 `working-style/principles.md`。

## 模板

```markdown
---
title: 2026-11-25
updated: 2026-11-25
confidence: high
status: active
scope: global
source: 行为推断
---

# 2026-11-25

## 返工

- 原方案：
  改成了：
  原因：

## 例外

- 破了哪条：
  为什么这次可以：

## 本人原话

-
```

## 不记什么

会话中的临时状态、工具报错、一次性搜索结果、已经写在 commit message 里的东西。
判断标准同 `AGENTS.md` 第 3 节：**未来的模型读到这条，行为会变吗？**
